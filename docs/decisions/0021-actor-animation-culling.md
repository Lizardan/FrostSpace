# 0021. Анимация актёров не отсекается по границам рендерера

- Статус: Accepted
- Дата: 2026-10-24
- Дополняет: [0009](0009-robot-animals.md)

## Контекст

Животные и роботы двигаются кодом (патруль `NpcController`, `AirPatrolController`,
локомоция игрока, ходьба в меню), а анимация — отдельный слой: Animator на визуальной
модели, клипы in-place, `applyRootMotion` выключен у всех 33 префабов с Animator.

При этом у моделей из Blender два свойства складывались в один дефект:

- `Animator.cullingMode` по умолчанию — `CullUpdateTransforms`: когда Unity считает
  рендерер «за кадром», **кости перестают обновляться**.
- Скинные меши приходят из FBX с `localBounds` в масштабе арматуры. У волка это
  `0.07 × 0.02 × 0.04` м при габарите модели около метра — в 28 раз меньше правды.

Отсечение по таким границам врёт: модель видна, а рендерер считается невидимым. Стоило
отвернуть камеру — и животное замирало в последней позе, пока актёр продолжал идти
(«модель съехала с родителя»), а при возврате взгляда поза прыгала в текущую
(«перескочила»). Заодно врал сканер: подпись ставилась по центру тех самых 7 см.

## Решение

1. **`AnimatorCullingMode.AlwaysAnimate`** для всех скелетных актёров, которые двигаются
   кодом: `NpcController`, `AirPatrolController`, `MenuRobotWalker`, `RobotLocomotion`.
2. **`SkinnedMeshRenderer.updateWhenOffscreen = true`** у их мешей: Unity считает границы
   по факту, отсечение становится честным, а `Renderer.bounds` годится для сканера.
3. Настройка живёт в одном месте — `Features/Npc/AnimationCulling.cs`, вызывается из
   `Awake` контроллеров. Префабы не патчатся: новые модели получат то же поведение
   без ручной правки 33 файлов.

## Последствия

- Поза актёра больше не зависит от того, куда смотрит игрок.
- Границы скинных мешей стали настоящими: у волка `1.99 × 1.22 × 0.68` вместо
  `0.07 × 0.02 × 0.04`. Сканер теперь ставит подпись по центру модели, а не по пивоту.
- Цена — пересчёт границ скиннинга у видимых актёров и анимация «за кадром».
  На 13 животных и 5 роботах в сцене это доли миллисекунды; на сотнях — понадобится
  вернуть отсечение с честными `localBounds` из FBX.
- Разница центров границ у тела и брони (~0.21 м) — не дефект сборки: броня это панели
  корпуса без головы и хвоста, поэтому её bounding box центрируется иначе. Проверено
  пересборкой с обнулёнными трансформами мешей: цифры не изменились, картинка совпадает.
- Настоящая причина «модель съезжает и перескакивает» оказалась в клипах: в них был
  запечён ход корня, а `applyRootMotion` выключен — см. [0022](0022-animal-clips-in-place.md).
  Отсечение по границам давало вторую половину симптома (замирание у края кадра).

## Альтернативы

- **Починить `localBounds` в префабах.** Отклонено: значения приходят из импорта FBX и
  перезаписываются при каждом переимпорте.
- **Оставить отсечение и запретить камере смотреть в сторону.** Невозможно.
- **`CullCompletely` + ручное включение анимации рядом с игроком.** Отклонено: сложнее и
  даёт те же рывки на границе зоны.
