# 0003. Режимы автоматизации: headless primary, MCP secondary

- Статус: Accepted
- Дата: 2026-10-18

## Контекст

Доступны четыре способа работы: headless-скрипты Blender, GUI-Blender с MCP, живой
Unity MCP и Unity batch-mode. Они не взаимозаменяемы по свойствам:

- Blender MCP-аддон **не работает в `--background`** по замыслу автора; headless при
  этом полностью функционален.
- GUI-Blender даёт живой вьюпорт, но зависит от окна, сессии и модальных операторов.
- Unity MCP быстрее перезапуска редактора, но требует открытого Unity.
- Unity batch-mode воспроизводим и годится для CI, но блокируется `UnityLockfile`, пока
  редактор открыт.

## Решение

| Задача | Режим |
|---|---|
| Сборка/экспорт/тесты/замеры Blender | **headless-скрипт** |
| Визуальная или интерактивная работа в Blender | **GUI + MCP**, по необходимости |
| Компиляция, Console, тесты, сцена в Unity | **живой Unity MCP** |
| Чистая проверка, CI, сборка | **Unity batch-mode** при закрытом редакторе |
| Долгий/unattended-прогон | headless/batch, не MCP |

Правила:

1. **Скрипт — источник истины**, MCP — обратная связь. Всё сохраняемое закрепляется
   скриптом.
2. **Не запускать GUI без необходимости**: окно и сессия — ресурс пользователя.
3. **Не запускать Unity batch при открытом редакторе**: сначала закрыть Unity.
4. **Не считать `compiling` готовностью.** После `refresh_unity` дождаться завершения.
5. **Долгие задачи не гонять через MCP**: таймауты и модальные окна делают результат
   ненадёжным.

## Последствия

- Быстрый и воспроизводимый путь по умолчанию.
- Визуальный контроль остаётся доступным, но не блокирует автоматизацию.
- Нужна дисциплина: результат MCP-правки переносится в скрипт, иначе он потеряется.

## Альтернативы

- **Всё через GUI-MCP.** Отклонено: медленно, не воспроизводимо, зависит от окна.
- **Всё через batch.** Отклонено: нет живой обратной связи для визуальных задач; Unity
  batch недоступен при открытом редакторе.
- **Считать MCP и скрипты равноправными источниками истины.** Отклонено: неизбежно
  расхождение и потеря изменений.
