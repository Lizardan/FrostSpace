# Планы к исполнению

`Assets/.Aura/plans/` — **единственное место**, где лежат планы FrostSpace. Она нужна, чтобы работу  
можно было продолжить после прерывания сессии другим агентом.

## Почему именно здесь

- Aura (`create_or_edit_plan`) пишет только в `Assets/.Aura/plans/` — путь зашит в инструмент и не  
  настраивается. Проект не спорит с инструментом: этот путь принят как общий для всех.
- Сюда же кладут планы остальные агенты (другие модели) и человек. Один путь, без зеркал,  
  junction'ов и копий.
- Папка начинается с точки: Unity такие каталоги не импортирует, `.meta` ей не нужны, в сборку  
  ничего не попадает.
- Git: файлы планов — локальная рабочая очередь, в git они не идут (`/Assets/.Aura/plans/*` в  
  `.gitignore`). Этот `README.md` — часть правил проекта и **коммитится**.

## Важно: папка скрытая для поиска

`rg`, `git grep` и часть IDE по умолчанию пропускают каталоги, имя которых начинается с точки.  
Если ищешь план — указывай путь явно:

```
rg --hidden "<что ищем>" Assets/.Aura/plans
```

или открывай папку напрямую.

## Имя файла

- План от человека или другого агента — `YYYY-MM-DD-<тема>.md`.
- План, созданный Aura, получает суффикс версии инструмента: `YYYY-MM-DD-<тема>_vN.md`  
  (`_v1`, `_v2` при переписывании). `<тема>` — это `plan_name`, который агент передаёт инструменту,  
  поэтому дата и тема в имени сохраняются.

## Правила

1. Перед многошаговой задачей создай здесь файл `YYYY-MM-DD-<тема>.md` и первым заголовком напиши  
   `# Текущий план — <дата>`.
2. В плане должны быть цель, этапы с чекбоксами `- [ ]`, затрагиваемые файлы, критерии приёмки и  
   известные риски.
3. По ходу работы отмечай выполненные пункты `- [x]` и дописывай в конец «Журнал выполнения»: что  
   сделано, что проверено, на чём остановился.
4. Если при старте сессии в этой папке есть план, сначала прочитай его и продолжи с первого  
   невыполненного пункта. Не удаляй чужой план, пока не убедишься, что он выполнен.
5. Когда план выполнен и проверен, удали его файл. Папка и этот `README.md` остаются.
6. Один файл — один текущий план. Не веди здесь архив: завершённые планы удаляются.

## Чего не делать

- Не создавать второй файл плана и не переносить план копированием.
- Не удалять и не перемещать саму папку `Assets/.Aura/plans/` — на неё ссылаются `AGENTS.md`,  
  `README.md` и `docs/PROJECT_MAP.md`.
- Не добавлять `.meta` внутрь `.Aura`: Unity этот каталог не импортирует.
