# План: читаемость палитр роботов в игре

Дата: 2026-10-18. Статус: **диагностика завершена, ждём выбор пользователя  
(уровень насыщенности и матовость), затем пересборка FBX**.

## Цель

Роботы в игровом свете читаются «тёмными» и «блеклыми» по сравнению со студийными  
превью. Сделать цвета читаемыми и сочными, не ломая дизайн-код (`docs/STYLE.md`).

## Диагностика (что установлено)

- Превью Blender — студийный рендер Workbench (`light=STUDIO`, `paint.sl`,  
  `color_type=MATERIAL`): свет сцены, солнце, снег и туман в нём не участвуют.  
  Игровой кадр так выглядеть не может — это «витрина», а не игровой свет.
- Шейдеры корректны: URP/Lit рисует альбедо 1:1 (контрольные щиты); Simple Lit темнее.
- Скриншоты MCP линейные — все замеры и показы перекодированы в sRGB (ловушка в  
  `docs/UNITY_MCP.md`).
- Туман (Linear 22–95 м) ближний план не трогает. Металличность в Unity не переносится  
  (`_Metallic`=0), roughness переносится как `_Smoothness` = 1 − roughness (док поправлен).
- Свет: солнце 1.15 + Trilight ambient ~1.0 — суммарно ~×2 к альбедо, цвета смещаются  
  в пастельную зону. Отражения неба (`Environment Reflections`) включены, `_Smoothness`  
  0.38–0.68, `reflectionIntensity`=1 — известный источник «вымывания» URP-сцен.
- **Главная причина блеклости — сами палитры манонасыщенные**: base/panel R1–R5 имеют  
  S 27–57 % (R4 base — 27 %, R1 base — 49 %); при игровом ×2 они читаются серыми.
- Пост-обработка через инструмент-скриншоты не видна (кадр рендерит отдельная камера  
  инструмента) — отдельная проверка при желании, см. `docs/UNITY_MCP.md`.

## Проверенные варианты (демо в Play, клоны материалов)

| Вариант                                                              | Результат                                                          |
| -------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Гамма sRGB^0.75/0.65/0.50                                            | светлее, но пастерит (насыщенность падает) — плохой рычаг          |
| HSV мягкий (S×1.35, V^0.8)                                           | слабый эффект                                                      |
| Заливка эмиссией 0.45×альбедо                                        | пересветляет в пастель — отклонено                                 |
| Матовость (smoothness 0.15 + ключи)                                  | небольшая, но полезная добавка                                     |
| Нейтральный ambient                                                  | почти не влияет                                                    |
| **Насыщенность в палитре без подъёма яркости (S^0.5 / S^0.3)**       | **работает: цвета читаются сочно, без пересвета**                  |
| Защищённая насыщенность (S^0.3 / S^0.2, белые нетронуты, cap ×2.2)   | рабочий вариант: цвет сочный, белые воротники/шерсть сохраняются   |
| Нейтрализация цвета ambient (Trilight → нейтральные)                 | слабый тёплый сдвиг теней, опция                                   |
| `ambientIntensity` 0.55–0.6 (в т.ч. с `DynamicGI.UpdateEnvironment`) | **не влияет на кадр в URP** (проверено дважды) — множитель инертен |

Монтажи: `AssetSource/Previews/Diagnostics/palette_round3_srgb.png` (0 текущее / 1 S^0.3  
защищённая / 2 +матовость / 3 S^0.2+матовость / 4 +нейтральный ambient), `palette_sat_srgb.png`  
(S^0.5 / S^0.3 / S^0.3+матовость — до защиты белых), `palette_rich_srgb.png`,  
`palette_variants_srgb.png`, `palette_steps_srgb.png`.

## Критерии приёмки

- Все пять роботов различимы по цвету и роли в игровом свете; не «серые и блеклые».
- Оттенки соответствуют дизайн-коду; силуэт (тёмный контур) сохраняется.
- Console без ошибок; EditMode-тесты 3/3; превью и игровой кадр согласованы по тону.

## Риски

- Пересборка FBX затрагивает визуальные префабы (материалы общие — обновятся сами).
- Пост-обработка как глобальный рычаг — вне этого плана (решение по сцене отдельно).
- Насыщенные палитры при смене света (день/ночь) надо будет перепроверить.
