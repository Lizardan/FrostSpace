# Планы к исполнению

Эта папка — очередь текущих многошаговых работ. Она нужна, чтобы работу можно было
продолжить после прерывания сессии другим агентом.

## Правила

1. Перед многошаговой задачей создай здесь файл `YYYY-MM-DD-<тема>.md` и первым
   заголовком напиши `# Текущий план — <дата>`.
2. В плане должны быть цель, этапы с чекбоксами `- [ ]`, затрагиваемые файлы,
   критерии приёмки и известные риски.
3. По ходу работы отмечай выполненные пункты `- [x]` и дописывай в конец
   «Журнал выполнения»: что сделано, что проверено, на чём остановился.
4. Если при старте сессии в этой папке есть план, сначала прочитай его и продолжи
   с первого невыполненного пункта. Не удаляй чужой план, пока не убедишься, что
   он выполнен.
5. Когда план выполнен и проверен, удали его файл. Папка и этот `README.md`
   остаются.
6. Один файл — один текущий план. Не веди здесь архив: завершённые планы удаляются.
